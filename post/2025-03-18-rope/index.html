Motivations: We Pursue Relative Positional Embedding

To incorporate positional information into the attention mechanism, we need to transform the original query and key vectors. The functions 𝑓(⋅,⋅) encode the position indices 𝑚 and 𝑛 into the query and key vectors respectively, resulting in position-aware representations 𝒒𝑚′ and 𝒌𝑛′.

𝒒𝑚′=𝑓(𝒒𝑚,𝑚),𝒌𝑛′=𝑓(𝒌𝑛,𝑛)

Typically, the attention score between a query at position 𝑚 and a key at position 𝑛 can be represented as a function 𝑔 that depends on both the content vectors (𝒒𝑚 and 𝒌𝑛) and their absolute positions (𝑚 and 𝑛) as follows:

Attn(𝒒𝑚′,𝒌𝑛′)=𝑔(𝒒𝑚,𝒌𝑛,𝑚,𝑛)

but we want the attention score to only depend on the relative position (𝑚−𝑛) rather than absolute positions 𝑚 and 𝑛. This gives the model a useful relative-position inductive bias, although it does not by itself guarantee extrapolation to unseen sequence lengths.

Goal of relative positional embedding: Thus our goal is to find a function 𝑔 which is only a function of 𝒒𝑚, 𝒌𝑛, and 𝑚−𝑛, instead of 𝑚 and 𝑛 themselves as follows:

Attn(𝒒𝑚′,𝒌𝑛′)=𝑔(𝒒𝑚,𝒌𝑛,𝑚−𝑛)

The RoPE is a solution to this goal.

RoPE (Rotary Position Embedding)

RoPE is a positional embedding that is a function of the relative position 𝑚−𝑛, which rotates the query and key vectors and then computes the attention score, which is a function of the relative position 𝑚−𝑛.

The base idea of RoPE is to rotate the query and key vectors by a certain angle, thus their dot product is a function of the relative position 𝑚−𝑛. RoPE used the property of rotation matrix multiplication. When we need to rotate a 2-dimensional vector (𝑥𝑦) by an angle 𝜃, we can multiply a rotation matrix (cos𝜃−sin𝜃sin𝜃cos𝜃) to the vector (𝑥𝑦), to get the rotated vector (𝑥cos𝜃−𝑦sin𝜃𝑥sin𝜃+𝑦cos𝜃).

In the following, suppose the query and key vectors are 2-dimensional vectors. We can rotate the query and key:

𝒒𝑚′=𝑓(𝒒𝑚,𝑚)=(cos𝑚𝜃−sin𝑚𝜃sin𝑚𝜃cos𝑚𝜃)(𝑞𝑚1𝑞𝑚2)𝒌𝑛′=𝑓(𝒌𝑛,𝑛)=(cos𝑛𝜃−sin𝑛𝜃sin𝑛𝜃cos𝑛𝜃)(𝑘𝑛1𝑘𝑛2)

The attention score is then:

Attn(𝒒𝑚′,𝒌𝑛′)=𝒒𝑚′𝑇⋅𝒌𝑛′=[(cos𝑚𝜃−sin𝑚𝜃sin𝑚𝜃cos𝑚𝜃)(𝑞𝑚1𝑞𝑚2)]𝑇⋅[(cos𝑛𝜃−sin𝑛𝜃sin𝑛𝜃cos𝑛𝜃)(𝑘𝑛1𝑘𝑛2)]=(𝑞𝑚1𝑞𝑚2)[(cos𝑚𝜃−sin𝑚𝜃sin𝑚𝜃cos𝑚𝜃)𝑇(cos𝑛𝜃−sin𝑛𝜃sin𝑛𝜃cos𝑛𝜃)](𝑘𝑛1𝑘𝑛2)=(𝑞𝑚1𝑞𝑚2)[(cos𝑚𝜃sin𝑚𝜃−sin𝑚𝜃cos𝑚𝜃)(cos𝑛𝜃−sin𝑛𝜃sin𝑛𝜃cos𝑛𝜃)](𝑘𝑛1𝑘𝑛2)=(𝑞𝑚1𝑞𝑚2)(cos((𝑛−𝑚)𝜃)−sin((𝑛−𝑚)𝜃)sin((𝑛−𝑚)𝜃)cos((𝑛−𝑚)𝜃))(𝑘𝑛1𝑘𝑛2)=𝑞𝑚1[𝑘𝑛1cos((𝑛−𝑚)𝜃)−𝑘𝑛2sin((𝑛−𝑚)𝜃)]+𝑞𝑚2[𝑘𝑛1sin((𝑛−𝑚)𝜃)+𝑘𝑛2cos((𝑛−𝑚)𝜃)]=(𝑞𝑚1𝑘𝑛1+𝑞𝑚2𝑘𝑛2)cos((𝑛−𝑚)𝜃)+(𝑞𝑚2𝑘𝑛1−𝑞𝑚1𝑘𝑛2)sin((𝑛−𝑚)𝜃)=𝑔(𝒒𝑚,𝒌𝑛,𝑚−𝑛)

thus we have shown that the attention score is a function of 𝒌𝑛, 𝒒𝑚, and their relative position 𝑚−𝑛, not the absolute positions 𝑚 and 𝑛 themselves.

RoPE Implementation (Half-and-Half Pairing)

This is the method used in your Python code and in many popular implementations like LLaMA. It is chosen for its extreme efficiency with vectorized operations. Instead of pairing adjacent dimensions (which is intuitive), this method pairs the first half of the dimensions with the second half.

For a vector 𝒒 with dim=𝑑:

  • Pair 0: dimension 0 is paired with dimension 𝑑2. (𝑞0,𝑞𝑑2)
  • Pair 1: dimension 1 is paired with dimension 𝑑2+1. (𝑞1,𝑞𝑑2+1)
  • …
  • Pair 𝑑2−1: dimension 𝑑2−1 is paired with dimension 𝑑−1. (𝑞𝑑2−1,𝑞𝑑−1)

In practice, the query and key vectors are not 2-dimensional vectors, but 𝑑-dimensional vectors (𝑑%2=0).

𝒒𝑚=(𝑞𝑚0𝑞𝑚1⋮𝑞𝑚𝑑−1),𝒌𝑛=(𝑘𝑛0𝑘𝑛1⋮𝑘𝑛𝑑−1)

We group each vector into 𝑑2 coordinate pairs. For the query these are (𝑞𝑚𝑖𝑞𝑚𝑖+𝑑2), and for the key they are (𝑘𝑛𝑖𝑘𝑛𝑖+𝑑2), where 𝑖=0,1,…,𝑑2−1.

For each pair 𝑖 (𝑖=0,1,…,𝑑2−1), define the angular frequency 𝜃𝑖=1𝜔2𝑖𝑑=1100002𝑖𝑑, where 𝜔 is the RoPE base (typically 10000). At position 𝑚, the pair is rotated by the angle 𝑚𝜃𝑖.

Thus small pair indices have higher frequencies and larger rotation angles at a fixed position, while large pair indices have lower frequencies and smaller rotation angles.

The rotated query vector becomes:

𝒒𝑚′=(𝑞𝑚0cos(𝜃0𝑚)−𝑞𝑚𝑑2sin(𝜃0𝑚)𝑞𝑚1cos(𝜃1𝑚)−𝑞𝑚𝑑2+1sin(𝜃1𝑚)⋮𝑞𝑚𝑑2−1cos(𝜃𝑑2−1𝑚)−𝑞𝑚𝑑−1sin(𝜃𝑑2−1𝑚)𝑞𝑚0sin(𝜃0𝑚)+𝑞𝑚𝑑2cos(𝜃0𝑚)𝑞𝑚1sin(𝜃1𝑚)+𝑞𝑚𝑑2+1cos(𝜃1𝑚)⋮𝑞𝑚𝑑2−1sin(𝜃𝑑2−1𝑚)+𝑞𝑚𝑑−1cos(𝜃𝑑2−1𝑚))

Similarly for the key vector:

𝒌𝑛′=(𝑘𝑛0cos(𝜃0𝑛)−𝑘𝑛𝑑2sin(𝜃0𝑛)𝑘𝑛1cos(𝜃1𝑛)−𝑘𝑛𝑑2+1sin(𝜃1𝑛)⋮𝑘𝑛𝑑2−1cos(𝜃𝑑2−1𝑛)−𝑘𝑛𝑑−1sin(𝜃𝑑2−1𝑛)𝑘𝑛0sin(𝜃0𝑛)+𝑘𝑛𝑑2cos(𝜃0𝑛)𝑘𝑛1sin(𝜃1𝑛)+𝑘𝑛𝑑2+1cos(𝜃1𝑛)⋮𝑘𝑛𝑑2−1sin(𝜃𝑑2−1𝑛)+𝑘𝑛𝑑−1cos(𝜃𝑑2−1𝑛))

When we compute the attention score between these rotated vectors, each pair contributes a term that depends on the relative position (𝑚−𝑛), similar to the 2D case we analyzed earlier. The different frequencies 𝜃𝑖=𝜔−2𝑖𝑑 allow the model to capture position-dependent patterns at different scales.

Thus we have:

𝒒𝑚′𝑇⋅𝒌𝑛′=∑𝑖=0𝑑2−1[(𝑞𝑚𝑖𝑘𝑛𝑖+𝑞𝑚𝑖+𝑑2𝑘𝑛𝑖+𝑑2)cos((𝑛−𝑚)𝜃𝑖)+(𝑞𝑚𝑖+𝑑2𝑘𝑛𝑖−𝑞𝑚𝑖𝑘𝑛𝑖+𝑑2)sin((𝑛−𝑚)𝜃𝑖)]=𝑔(𝒒𝑚,𝒌𝑛,𝑚−𝑛)

Example:

Let’s walk through how the code achieves this with a concrete example where dim =8. The input query vector is 𝒒=[𝑞0,𝑞1,𝑞2,𝑞3,𝑞4,𝑞5,𝑞6,𝑞7].

Pairing: The pairs will be: (𝑞0,𝑞4),(𝑞1,𝑞5),(𝑞2,𝑞6),(𝑞3,𝑞7).

Frequency: There are 𝑑2=4 angular frequencies: 𝜃0,𝜃1,𝜃2,𝜃3. At position 𝑚, the angle for pair 𝑖∈[0,1,2,3] is:

𝜑𝑚,𝑖=𝑚𝜃𝑖=𝑚100002𝑖𝑑

where 𝑑 is the dimension. For example, 𝜑𝑚,0=𝑚100002∗08=𝑚.

We construct the angles for a given position 𝑚 as [𝜑𝑚,0,𝜑𝑚,1,𝜑𝑚,2,𝜑𝑚,3,𝜑𝑚,0,𝜑𝑚,1,𝜑𝑚,2,𝜑𝑚,3].

The final cos and sin tensors will therefore have this duplicated structure. For position m:

cos𝑚=[cos(𝜑𝑚,0),cos(𝜑𝑚,1),cos(𝜑𝑚,2),cos(𝜑𝑚,3),cos(𝜑𝑚,0),cos(𝜑𝑚,1),cos(𝜑𝑚,2),cos(𝜑𝑚,3)]

sin𝑚=[sin(𝜑𝑚,0),sin(𝜑𝑚,1),sin(𝜑𝑚,2),sin(𝜑𝑚,3),sin(𝜑𝑚,0),sin(𝜑𝑚,1),sin(𝜑𝑚,2),sin(𝜑𝑚,3)]

Now, let’s see how the rotation is applied to 𝒒=[𝑞0,𝑞1,𝑞2,𝑞3,𝑞4,𝑞5,𝑞6,𝑞7].

We construct half-rotated query vector as 𝒒rotated=[−𝑞4,−𝑞5,−𝑞6,−𝑞7,𝑞0,𝑞1,𝑞2,𝑞3].

We then construct the query vector 𝒒𝑚′ as:

𝒒𝑚′=(𝒒⋅cos)+(𝒒rotated⋅sin)

If we let our 2D vector be (𝑞0,𝑞4) and the rotation angle be 𝜑𝑚,0, the standard 2D rotation formulas are:

  • 𝑞0′=𝑞0cos(𝜑𝑚,0)−𝑞4sin(𝜑𝑚,0)
  • 𝑞4′=𝑞0sin(𝜑𝑚,0)+𝑞4cos(𝜑𝑚,0)

As you can see, the code perfectly implements the 2D rotation for the pair (𝑞0,𝑞4). This same logic applies simultaneously to all other pairs: (𝑞1,𝑞5), (𝑞2,𝑞6), (𝑞3,𝑞7).

  • 𝑞1′=𝑞1cos(𝜑𝑚,1)−𝑞5sin(𝜑𝑚,1)
  • 𝑞5′=𝑞1sin(𝜑𝑚,1)+𝑞5cos(𝜑𝑚,1)
  • 𝑞2′=𝑞2cos(𝜑𝑚,2)−𝑞6sin(𝜑𝑚,2)
  • 𝑞6′=𝑞2sin(𝜑𝑚,2)+𝑞6cos(𝜑𝑚,2)
  • 𝑞3′=𝑞3cos(𝜑𝑚,3)−𝑞7sin(𝜑𝑚,3)
  • 𝑞7′=𝑞3sin(𝜑𝑚,3)+𝑞7cos(𝜑𝑚,3)

Extending RoPE to Longer Contexts

Vanilla RoPE is trained with a fixed maximum context length 𝐿. For positions 𝑚>𝐿, the phase values 𝑚⋅𝜃𝑖 exceed the range the model encountered during training, degrading performance. Three principal strategies address this: modifying the base frequency (ABF), interpolating positions uniformly (PI), and combining dimension-wise interpolation with temperature scaling (YaRN).

Recall that the phase (rotation angle) for dimension pair 𝑖 at position 𝑚 is:

𝜃𝑖⋅𝑚=𝑚𝜔2𝑖𝑑,𝜔=10000

The goal of context extension is to keep phase values at positions 𝑚≤𝐿′ within the range the model learned during training (𝑚≤𝐿). We write 𝛼=𝐿′𝐿 for the context extension ratio throughout.

We can express all extension methods in a general interpolation framework. Given the original RoPE encoding 𝑓(𝒙𝑚,𝑚,𝜃𝑖), each method defines a modified encoding:

𝑓′(𝒙𝑚,𝑚,𝜃𝑖)=𝑓(𝒙𝑚,𝑔(𝑚),ℎ(𝜃𝑖))

where 𝑔 transforms positions and ℎ transforms frequencies. The choice of 𝑔 and ℎ distinguishes the methods.

ABF (Adjusted Base Frequency)

ABF extends the context by replacing the base frequency 𝜔 with a larger value 𝜔′=𝑠⋅𝜔 (𝑠>1), directly reducing the angular frequencies and slowing phase accumulation. In the general framework, ABF sets 𝑔(𝑚)=𝑚 (positions unchanged) and ℎ(𝜃𝑖)=𝜃𝑖𝑠2𝑖𝑑 (frequencies reduced).

Derivation

With the scaled base 𝜔′=𝑠⋅𝜔, the phase for dimension pair 𝑖 at position 𝑚 becomes:

𝑚(𝑠⋅𝜔)2𝑖𝑑=𝑚𝑠2𝑖𝑑⋅𝜔2𝑖𝑑

Historical Context: From NTK Theory to Base Scaling

The idea of modifying the base frequency to extend context did not originate in a traditional research lab. In late June 2023 — just days after Chen et al. published Position Interpolation — a pseudonymous Reddit user, u/bloc97, posted “NTK-Aware Scaled RoPE” on the r/LocalLLaMA forum. The post demonstrated that by changing only three lines of code (replacing 𝜔=10000 with a larger base), LLaMA 7B could handle 8K+ token sequences without any fine-tuning and with minimal perplexity degradation. This sparked a rapid wave of community-driven innovation: u/emozilla proposed Dynamic NTK scaling shortly after, and bloc97 followed up in July with NTK-by-parts — each refinement building on the last within weeks rather than months. By August, Meta’s Code Llama had adopted a base of 1000000, validating the approach at production scale. Peng et al. formalized the full method as YaRN in September 2023 (published at ICLR 2024).

The name “NTK-aware” comes from Neural Tangent Kernel theory (Jacot et al., 2018). The key theoretical connection is this: RoPE’s position encoding [cos(𝑚𝜃𝑖),sin(𝑚𝜃𝑖)] is essentially a random Fourier feature mapping, and NTK theory predicts that such Fourier features must preserve a spectrum of frequencies matching the target function’s complexity. When PI compresses all frequencies uniformly by 1𝛼, it narrows the entire spectral bandwidth — destroying the high-frequency components that the network relies on for fine-grained local position discrimination. Base scaling, by contrast, distributes the interpolation pressure non-uniformly: dimensions with small 𝑖 (high frequency, encoding local patterns) are barely changed, while dimensions with large 𝑖 (low frequency, encoding global patterns) absorb most of the compression. This preserves the model’s sensitivity to nearby token relationships while still preventing out-of-distribution phase values at long distances.

How Modifying the Base Changes Phase Growth

We can factor the ABF phase as:

𝑚𝑠2𝑖𝑑⋅𝜔2𝑖𝑑=1𝑠2𝑖𝑑⋅𝑚𝜔2𝑖𝑑⏟vanilla phase

Thus the phase reduction factor compared to vanilla RoPE is 1𝑠2𝑖𝑑, which is dimension-dependent:

  • For 𝑖=0: reduction =1𝑠0=1 — the highest-frequency component is unchanged.
  • For 𝑖=𝑑2−1: reduction =1𝑠𝑑−2𝑑≈1𝑠 — the lowest-frequency component sees the largest reduction.

ABF primarily compresses the low-frequency (high-dimensional) pairs while leaving the high-frequency (low-dimensional) pairs nearly intact, because the exponent 2𝑖𝑑 amplifies the effect of 𝑠 for larger 𝑖.

Choosing 𝑠: NTK-Aware Scaling

To extend from context length 𝐿 to 𝐿′, we require the lowest-frequency pair (𝑖=𝑑2−1) at position 𝐿′ to not exceed its vanilla phase at position 𝐿:

𝐿′𝑠𝑑−2𝑑⋅𝜔𝑑−2𝑑≤𝐿𝜔𝑑−2𝑑𝑠𝑑−2𝑑≥𝐿′𝐿𝑠≥(𝐿′𝐿)𝑑𝑑−2

The minimum value gives the NTK-aware base:

𝜔′=𝜔⋅(𝐿′𝐿)𝑑𝑑−2

Practical Base Frequency Values

The theoretical analysis above predicts the minimum base frequency needed for a target context length. In practice, several prominent models adopt large base values that align with these bounds:

  • Code Llama: 𝜔=1000000 (extending from 4K to 100K tokens).
  • Meta long-context models: 𝜔=500000 (extending LLaMA-family models to 32K–128K tokens).

Men et al. (2024) establish a tighter theoretical bound by requiring the cumulative rotation 𝐵𝑚,𝜃=∑𝑖cos(𝑚𝜃𝑖)≥0 for effective positional discrimination. Their analysis yields minimum base requirements that grow rapidly with context length: approximately 4.3×103 for 4K context, 6.4×105 for 32K, and 7.8×106 for 128K. Practical choices such as 500000–1000000 are near or above the quoted 32K bound but below the quoted 128K bound, so they should not be described as satisfying the latter sufficient condition.

A key advantage of ABF over pure position interpolation is that it preserves local positional resolution — nearby tokens at low dimension pairs still see approximately the same phase differences as in vanilla RoPE, since the high-frequency components are nearly unchanged. The cost is that inter-dimensional phase ratios are distorted, as we will see when comparing with PI and YaRN below.

Limitations of Large Scaling Factors

While ABF successfully extends context length, increasing the scaling factor 𝑠 introduces growing distortions that limit its effectiveness. Recall from the stability analysis that ABF modifies the inter-dimensional phase ratio by an extra factor of 𝑠2(𝑗−𝑖)𝑑. As 𝑠 grows large, this factor becomes substantial for dimension pairs that are far apart in index — meaning the model encounters inter-dimensional relationships that deviate significantly from what it learned during pre-training. In the extreme, with 𝑠=100 and 𝑑=128, the ratio between the lowest and highest frequency pairs is distorted by a factor exceeding 𝑠𝑑−2𝑑≈97×, a regime well outside the model’s training distribution.

Research by Liu et al. (2023) on scaling laws for RoPE-based extrapolation reveals a counterintuitive finding: the default base of 𝜔=10000 can give particularly poor extrapolation performance when models are fine-tuned for longer contexts. Performance can improve when the base is adjusted in either direction. Smaller bases produce a different, more gradual degradation regime, while sufficiently large bases can work well within a target range but may exhibit a sharper failure beyond it. Their analysis introduces a critical dimension separating frequencies that complete full cycles within the training context from those that do not. Under the indexing convention used here, 𝜃𝑖=𝜔−2𝑖𝑑 decreases and the wavelength 𝜆𝑖 increases with 𝑖: small-𝑖 pairs have short wavelengths and complete more cycles, whereas large-𝑖 pairs have long wavelengths and may cover only a partial cycle. Any numerical critical index must be interpreted using the paper’s precise dimension convention before being mapped to the pair index 𝑖 used here.

Men et al. (2024) reinforce this picture with their finding of “superficial long-context ability.” Models with an insufficiently large base can achieve low perplexity on long sequences — appearing to handle extended contexts — while actually failing at tasks that require precise long-range retrieval. The perplexity metric masks the model’s inability to attend to distant tokens with high specificity, because the cumulative rotation bound 𝐵𝑚,𝜃=∑𝑖cos(𝑚𝜃𝑖) approaches zero before the perplexity fully degrades. This gap between perplexity and retrieval accuracy is an important caveat when evaluating any base-scaling approach.

PI (Position Interpolation)

Position Interpolation takes the simplest possible approach: instead of modifying frequencies, it scales down all positions to fit within the trained range. In the general framework, PI sets 𝑔(𝑚)=𝑚𝛼 (positions compressed) and ℎ(𝜃𝑖)=𝜃𝑖 (frequencies unchanged).

Derivation

Given the context extension ratio 𝛼=𝐿′𝐿, PI maps each position:

𝑚→𝑚𝛼

The frequencies 𝜃𝑖 remain unchanged. The phase at position 𝑚 becomes:

(𝑚𝛼)⋅𝜃𝑖=𝑚𝛼⋅𝜔2𝑖𝑑

How Position Interpolation Changes Phase

We can factor the PI phase as:

𝑚𝛼⋅𝜔2𝑖𝑑=1𝛼⋅𝑚𝜔2𝑖𝑑⏟vanilla phase

The reduction factor is 1𝛼, which is uniform across all dimensions.

At the extended boundary 𝑚=𝐿′:

(𝐿′𝛼)⋅𝜃𝑖=𝐿⋅𝜃𝑖

The phase at position 𝐿′ under PI equals the phase at position 𝐿 under vanilla RoPE for every dimension 𝑖. The model sees the same range of phase values it was trained on, just at a finer positional granularity.

Stability of Phase Ratios

Why PI preserves inter-dimensional relationships. Under vanilla RoPE, the inter-dimensional phase ratio between pairs 𝑖 and 𝑗 is:

𝜃𝑖⋅𝑚𝜃𝑗⋅𝑚=𝜔2(𝑗−𝑖)𝑑

Under PI, this ratio is preserved exactly (the 1𝛼 cancels):

(𝑚𝛼)⋅𝜃𝑖(𝑚𝛼)⋅𝜃𝑗=𝜃𝑖𝜃𝑗=𝜔2(𝑗−𝑖)𝑑

Under ABF, the modified frequencies 1(𝑠𝜔)2𝑖𝑑 change this ratio to:

(𝑠𝜔)2(𝑗−𝑖)𝑑=𝑠2(𝑗−𝑖)𝑑⋅𝜔2(𝑗−𝑖)𝑑

The extra factor 𝑠2(𝑗−𝑖)𝑑 distorts the learned inter-dimensional relationships. Since PI preserves these ratios exactly, it typically requires less fine-tuning and is more stable when extending context length.

Limitations of Uniform Interpolation

While PI elegantly preserves inter-dimensional phase ratios, the uniform 1𝛼 compression has a significant drawback. High-frequency dimension pairs (small 𝑖) already have short wavelengths — they encode fine-grained local position differences. Compressing these by 1𝛼 reduces the model’s ability to distinguish nearby positions, effectively losing high-frequency positional information.

Low-frequency pairs (large 𝑖), on the other hand, have wavelengths much longer than the training context 𝐿. For these dimensions, the model has never seen a full rotation cycle during training, so the phase values encountered at positions up to 𝐿 occupy only a small arc. These dimensions genuinely need interpolation to avoid out-of-distribution phase values at positions beyond 𝐿. But high-frequency dimensions already complete many full rotations within [0,𝐿], so they can tolerate positions beyond 𝐿 without extrapolation problems.

This observation — that different dimensions require different amounts of interpolation — motivates the more sophisticated YaRN method.

YaRN (Yet Another RoPE ExtensioN)

YaRN addresses the limitations of both ABF and PI by combining dimension-wise interpolation (NTK-by-parts) with attention temperature scaling. Rather than applying a single strategy uniformly, YaRN classifies each dimension pair according to how much interpolation it needs and blends PI with identity scaling accordingly.

Wavelength Analysis

Each dimension pair 𝑖 has a characteristic wavelength — the number of positions for a full 2𝜋 rotation:

𝜆𝑖=2𝜋𝜃𝑖=2𝜋⋅𝜔2𝑖𝑑

We define the ratio of the training context length to this wavelength:

𝑟(𝑖)=𝐿𝜆𝑖=𝐿2𝜋⋅𝜔2𝑖𝑑

This ratio 𝑟(𝑖) tells us how many full rotation cycles dimension 𝑖 completes within the training window:

  • High ratio (𝑟(𝑖)≫1): the model has seen many full cycles during training. This dimension encodes local positional patterns and can tolerate extrapolation to positions beyond 𝐿 without problems. No interpolation is needed.
  • Low ratio (𝑟(𝑖)≪1): the model has seen only a small arc of the full rotation. Positions beyond 𝐿 would produce phase values the model has never encountered. Full interpolation (as in PI) is needed.
  • Intermediate ratio: a blend of interpolation and identity is appropriate.

NTK-by-Parts Interpolation

YaRN uses a ramp function 𝛾(𝑟) to smoothly transition between full interpolation and no interpolation, based on the ratio 𝑟(𝑖):

𝛾(𝑟)={0if𝑟<𝛼lo1if𝑟>𝛼hi𝑟−𝛼lo𝛼hi−𝛼lootherwise

where 𝛼lo and 𝛼hi are hyperparameters controlling the transition boundaries. For the LLaMA model family, the recommended values are 𝛼lo=1 and 𝛼hi=32.

The choice of these boundaries has a precise physical interpretation tied to rotation cycles. A dimension pair with 𝑟(𝑖)<1 — that is, 𝑟(𝑖)<𝛼lo — has a wavelength longer than the training context 𝐿. The model has seen less than one full rotation cycle for this dimension during pre-training, so any position beyond 𝐿 pushes the phase into entirely uncharted territory. These dimensions are the most vulnerable to extrapolation failure and must receive full PI-style interpolation. At the other extreme, 𝑟(𝑖)>32 means the model has observed 32 or more complete rotation cycles during training. The positional patterns at these frequencies are thoroughly learned; the model can reliably extrapolate because the periodic structure is well established. Leaving these dimensions unchanged preserves the fine-grained local position sensitivity that PI would destroy.

This connects directly to the critical dimension concept from Liu et al. (2023): the boundary 𝑟(𝑖)=1 corresponds roughly to the index 𝑑extra where dimensions transition from having seen partial rotations to having seen full cycles. YaRN’s ramp function effectively operationalizes this theoretical boundary, with 𝛼lo=1 marking the onset of safe extrapolation and 𝛼hi=32 marking the point of full confidence. The linear transition between them provides a smooth blend that avoids abrupt changes in the frequency spectrum — a design choice validated empirically across the LLaMA model family.

The modified frequency for dimension pair 𝑖 is then:

ℎ(𝜃𝑖)=(1−𝛾(𝑟(𝑖)))⋅𝜃𝑖𝛼+𝛾(𝑟(𝑖))⋅𝜃𝑖

We can factor this to understand the per-dimension behavior:

ℎ(𝜃𝑖)=𝜃𝑖⏟vanilla freq.⋅[𝛾(𝑟(𝑖))+1−𝛾(𝑟(𝑖))𝛼]

The three regimes are:

  • When 𝛾=0 (low-frequency dimensions, 𝑟(𝑖)<𝛼lo): ℎ(𝜃𝑖)=𝜃𝑖𝛼, identical to PI — full interpolation.
  • When 𝛾=1 (high-frequency dimensions, 𝑟(𝑖)>𝛼hi): ℎ(𝜃𝑖)=𝜃𝑖, the frequency is unchanged — no interpolation at all.
  • When 0<𝛾<1 (transition region): ℎ(𝜃𝑖)=𝜃𝑖⋅[𝛾+1−𝛾𝛼], a linear blend between PI and identity.

Temperature Scaling

NTK-by-parts interpolation solves the dimension-wise frequency problem, but it introduces a subtler issue: the modified frequencies change the entropy of the attention distribution. When we interpolate some dimensions but not others, the effective magnitude of the dot-product attention scores shifts, causing the softmax to become either too sharp or too diffuse compared to the original model.

YaRN corrects this with a temperature parameter 𝑡 applied to the attention logits:

Attn(𝒒𝑚′,𝒌𝑛′)=softmax(𝒒𝑚′𝑇𝒌𝑛′𝑡⋅𝑑)

The temperature is derived from the extension ratio 𝛼 via an empirically calibrated formula:

1𝑡=0.1⋅ln(𝛼)+1

Solving for 𝑡:

𝑡=1(0.1⋅ln(𝛼)+1)2

Since 𝛼>1, we have 0.1⋅ln(𝛼)+1>1, which gives 𝑡<1. Dividing by 𝑡<1 scales up the attention logits, sharpening the attention distribution. This counteracts the entropy increase caused by the modified frequencies, restoring the attention pattern to a distribution similar to what the model learned during training.

For example, with 𝛼=4: 1𝑡=0.1⋅ln(4)+1≈1.139, so 𝑡≈0.771.

The formula 1𝑡=0.1⋅ln(𝛼)+1 was found by empirical fitting, not theoretical derivation. Peng et al. applied NTK-by-parts with various scaling factors 𝛼 to LLaMA 7B, 13B, 33B, and 65B models without fine-tuning, sweeping over temperature values 𝑡 for each configuration to find the one minimizing perplexity. When they plotted 1𝑡 against ln(𝛼), the relationship turned out to be remarkably linear — and consistent across all four model sizes. They validated this across 896 documents from RedPajama at different token positions, confirming that the optimal temperature depends primarily on the extension ratio rather than on model size or input content.

The entropy change should be understood as an empirical property of the modified attention patterns, not as a consequence of every interpolated dimension contributing a smaller dot product. RoPE rotations preserve vector norms, and changing a phase does not make an individual dot-product contribution decrease monotonically. Empirically, however, NTK-by-parts changes the distribution of logits across key positions and can make the resulting softmax too diffuse. Dividing by 𝑡<1 is equivalent to multiplying the logits by 1𝑡>1, sharpening the distribution and bringing its entropy profile closer to the one observed during pre-training.

We note that the temperature formula is architecture-dependent. The coefficient 0.1 in 1𝑡=0.1⋅ln(𝛼)+1 was fit specifically for LLaMA models. For Mistral-7B, the optimal coefficient shifts to approximately 0.07, reflecting differences in head dimension, number of attention heads, and the learned attention patterns. In the general parametric form 1𝑡=𝑎⋅ln(𝛼)+𝑏, both 𝑎 and 𝑏 may need re-fitting when applying YaRN to a new architecture — though the logarithmic relationship with 𝛼 appears to be universal.

Dynamic Scaling and Dynamic NTK

In practice, the extension ratio need not be fixed at inference time. A dynamic schedule can compute it from the current sequence length 𝑙′:

𝛼=max(𝑙′𝐿,1)

When 𝑙′≤𝐿, we have 𝛼=1, so a dynamically scaled method can reduce to vanilla RoPE. As 𝑙′ exceeds 𝐿, its scaling gradually activates. Dynamic NTK specifically applies such a schedule to the NTK-aware base-scaling formula; it is distinct from YaRN, which combines NTK-by-parts interpolation with attention scaling. A YaRN implementation may also choose its scale dynamically, but that should be described as dynamic YaRN scaling rather than treating Dynamic NTK and YaRN as the same method. Dynamic scaling also complicates KV caching because changing the scale can require previously cached rotated keys to be recomputed or handled specially.

YaRN achieves the lowest perplexity at 128K tokens with the 13B model, outperforming Code Llama despite the latter using a much larger base frequency of 𝜔=1000000. PI, while theoretically elegant, fails catastrophically beyond its trained extension range — perplexity explodes past 32K tokens for the Together AI model. On passkey retrieval — a stricter test of whether the model can actually attend to a specific token at arbitrary distances — YaRN (𝑠=32, 128K) achieves 99.4% accuracy, matching Code Llama’s 100K result.

The training efficiency comparison is equally striking. NTK-aware scaling from Xiong et al. requires approximately 64,000 A100 GPU-hours of continued pre-training. PI (Chen et al.) brings this down to roughly 640 GPU-hours. YaRN requires only 384 GPU-hours total — 256 for the initial 64K extension plus 128 for the additional 128K stage — using approximately 0.1% of the original pre-training data and converging in just 400 optimization steps for the first stage. This makes YaRN the most compute-efficient method by a significant margin while achieving superior or comparable results.

An important caveat emerges from these results: perplexity alone is not a reliable indicator of long-context capability. YaRN with 𝑠=32 achieves similar perplexity to 𝑠=16, yet the 𝑠=32 model scores meaningfully higher on passkey retrieval, demonstrating better ability to attend to distant tokens. This gap suggests that perplexity primarily captures local language modeling quality, while retrieval tasks probe whether the model can genuinely leverage the full extended context. When evaluating RoPE extension methods, we recommend testing with retrieval-based benchmarks (such as passkey retrieval or needle-in-a-haystack) alongside perplexity.

From a practical standpoint, YaRN incurs zero computational overhead at inference time. The modified frequencies are pre-computed and cached, just as in vanilla RoPE, and the temperature scaling amounts to a single scalar multiplication on the attention logits. YaRN is natively supported in HuggingFace Transformers via rope_type: "yarn", and has been adopted by production models including Qwen, DeepSeek, and later LLaMA variants — making it the de facto standard for RoPE-based context extension.

We can summarize the key trade-offs as follows:

  • Base scaling and ABF modify the frequency spectrum in a dimension-dependent way, preserving high-frequency (local) positional resolution at the cost of distorting inter-dimensional phase ratios.
  • PI applies a uniform reduction that perfectly preserves phase ratios but sacrifices high-frequency resolution.
  • YaRN achieves the best of both worlds: it preserves high-frequency dimensions (where the model can extrapolate) while interpolating only the low-frequency dimensions (where extrapolation would fail), and corrects the resulting entropy shift via temperature scaling.
